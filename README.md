# PJL — version jouable

[Jouer dans le navigateur](https://anquetin10-cpu.github.io/PJL/)

Version web compilée de Jumping League Sim. Prototype non officiel inspiré de la Premier Jumping League.

Sur téléphone ou tablette, jouer en mode paysage. Aucun VPN nécessaire.

Ce dépôt contient uniquement les fichiers nécessaires au jeu. Le dépôt de développement reste privé.
